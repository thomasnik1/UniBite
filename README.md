# UniBite
A web platform that aims to help students share food within the academic community. UniBite was developed as part of the "Web Programming and Systems" course at the Computer Engineering and Informatics Department (CEID), University of Patras.

## Project Description
UniBite provides students with their first hands-on experience in web development. The focus of this project is to create a web platform for food sharing that's used by the academic community. The idea behind UniBite is that students can cook large portions of food, keep some for themselves, and share the rest of the portions with other students, users of UniBite. With each portion the users give out, they earn back points that they can use to claim food from other users.

## Technologies Used
**Front-end**: **ReactJS** was used in order to design a responsive UI.
**Back-end**: **Node.js** along with **Express** was used to create the server.
**Database**: **MySQL** was used in order to build and maintain the database fro the platform.
**Containerization** : **Docker & Docker Compose** were used in order to ensure environment stability and transferability.
